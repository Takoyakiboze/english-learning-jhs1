# ことばの時間：Expo UI検証版

今回の目的はiPhone・iPad向け画面と操作の確認です。Expo SDK 58 / React Native / TypeScriptで実装しています。モバイルのExpo GoもSDK 58対応版を使用してください。

GitHub Pagesでブラウザ版を公開する手順と検証結果は [GitHub Pages公開前の確認](./GITHUB_PAGES.md) を参照してください。

## 起動

この作業フォルダーではPowerShellで以下を実行します。付属のポータブルNodeを自動でPATHに追加します。

```powershell
cd english-learning-jhs1\expo-ui
powershell -ExecutionPolicy Bypass -File .\start-preview.ps1
```

標準のNode環境では `npm ci` の後に `npm start -- --go --clear --port 8082`。表示されたQRコードを対応するExpo Goで読み取ります。同じネットワークを使ってください。PCではターミナルの `w` キーでWeb画面を開けます。`npm run web -- --port 8082` でも起動できます。

SDK更新後は起動中の古いExpoサーバーを `Ctrl+C` で停止してから起動し直してください。起動スクリプトはExpo Goモードを指定し、Metroのキャッシュを消して起動します。

`expo run:ios` のネイティブビルドにはMacとXcodeが必要です。今回はWindowsでも確認できるExpo Go / Webを使います。

## 確認できる流れ

1. 呼び名・対象を選んで初期設定。
2. レベル1から20問の学習。四択・スペル・穴埋めを回答。解放済みのレベルで過去に間違えた単語を5問優先して組み込みます。該当履歴が5語未満なら全語を入れ、残りを現在のレベルの問題で補います。
3. 誤答時は正解を選択・入力し、末尾の復習問題へ。訂正・復習は初回点数に加算しません。
4. 初回20/20正解なら10分を付与。19/20以下なら付与しません。20問に含めた過去の誤答の復習は通常どおり採点し、その場で追加する訂正・再出題では点数を増やしません。
5. 報酬画面で利用開始・利用終了・再制限のデモ表示。
6. 記録、苦手単語、教材、目標、保護者設定、例外解除、初期化を確認。
7. ホームから現在レベルの10問の実力確認テスト。報酬・習得判定・レベル変更はありません。

1,200語を10レベル・各120語に分けています。通常学習の本問で、同じ単語に別々の完了セットで2回連続正解すると「習得済み」になります。そのセット全体が不合格でも、正解した単語の習得回数は進みます。誤答で連続正解をリセットし、その場の訂正・末尾の再出題・中断したセット・確認テストでは習得回数を増やしません。ヒントの利用は今回減点しません。

120語すべてを習得すると次のレベルへ自動で進みます。出題は現在レベルと解放済みの復習語のみです。未出題・未習得の語を優先し、同じ少数の語を繰り返して進めなくなることを防ぎます。以前のレベルの誤答も5問枠で復習します。一度習得した語と解放したレベルは、後の復習で誤答しても取り消さず、苦手履歴へ戻します。全10レベル習得後も解放済みの全語から復習できます。

スペルは前後空白と大文字・小文字を正規化します。教材は小学校の復習を含む中1向けの基本語彙1,200語で、全語に意味・例文・和訳を付けています。教科書の網羅性・公式の学年別リストへの準拠を保証するものではありません。

記録画面で教材を英語・日本語検索し、20カテゴリー・10レベルで絞り込めます。一度に20語ずつ表示します。未解放レベルも教材の閲覧はできますが、出題されません。目標画面で10段階の習得状況を確認できます。目標名を切り替えてもレベルは飛ばせません。

間違えた単語のID・誤答回数・最終誤答日時・最終復習日時と、単語ごとの習得回数・習得済み状態は端末内に保存します。以前の誤答履歴も維持し、まだ未解放のレベルの語は出題対象から外します。復習間隔が長い単語から優先して選び、出題順はランダムにします。学習結果の一覧・報酬・設定はメモリ保存です。

20問は本問の数です。今のセットで間違えた単語は、従来どおり末尾に追加して再出題します。苦手履歴がほぼ全教材に及び通常問題が15語に満たない場合は、残りも苦手単語で補います。実力確認テストは従来の10問で、復習5問の枠は適用しません。設定の「検証データを初期化」で保存した復習履歴も消せます。

教材は `src/curriculum/words.json` に同梱し、通信なしで出題できます。編集用の原稿は `curriculum-source/`、方針と語数は [教材説明](./curriculum-source/README.md) を参照してください。

## 検証コマンド

```sh
npm run lint
npm run typecheck
npm run curriculum:check
npm test
npx expo export --platform ios --output-dir dist-ios
npx expo export --platform web --output-dir dist-web
```

操作テストは8082番のプレビューが起動している状態で実行します。初回は `npx playwright install chromium` が必要です。

仮定・課題・意思決定事項は [UI検証版の仮定と課題](../UI検証版の仮定と課題.md) を参照してください。
