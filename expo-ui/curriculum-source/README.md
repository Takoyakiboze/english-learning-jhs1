# 基本語彙1,200語

作成：2026-10-24。中1向けの教材拡充として、小学校で学ぶ基礎語彙と、中学校で使う日常語・基本動詞・機能語を選んだアプリ独自の教材です。

- 登録数は異なる見出し語1,200語。各語に日本語の意味、英文例文、その和訳、品詞、カテゴリー、安定IDがあります。
- 10レベル・各120語に分類。身近な基本語、日常の語、動作・性質、抽象的な表現へ進むアプリ独自の暫定難易度です。基礎語の選定、カテゴリー、綴りの長さを基準に初期分類しました。CEFR・英検・教科書の公認レベルではなく、専門家による全語の難易度校閲は未実施です。
- 固有名詞・月・曜日も含みます。五月の `May` と助動詞の `may` は異なる語として区別しています。
- 一つの単語に意味が複数ある場合、今回は一つの意味を主に扱います。全語義・全熟語・全活用形を収録した辞書ではありません。
- 学年別の公式な必修単語一覧ではなく、特定の教科書との照合・全件の第三者校閲は未実施です。必要な範囲や語義の追加・校閲を今後行います。
- 本文・訳・例文はこのアプリ用に作成しています。外部辞書・教科書の文章は転載していません。
- 例文は短い共通パターンも使用しています。出題前は対象語を単語単位で空欄にし、答え合わせ後に全文を表示します。
- スペル問題では同じ日本語訳で登録された別の単語も許容します。穴埋め問題では登録された対象語を正解とします。

## 編集方法

`01-nouns.txt` から `04-verbs.txt` が編集用原稿です。カテゴリー行は `@カテゴリー|品詞|例文パターン|和訳パターン`、単語行は `単語|意味|例文（任意）|和訳（任意）` です。パターンには `{word}`、`{meaning}`、`{article}` が使えます。

```sh
npm run curriculum:build
npm run curriculum:check
npm test
```

ビルドは重複と語数を確認してJSONを書き出します。チェックはID・見出し語の重複、意味・訳の欠落、例文に対象語が独立した単語として存在することを確認します。文法・訳の正確さや教科書の網羅性は、この機械検査だけでは保証できません。

レベルの割り当ては `levels.json` に全1,200語を明記しています。通常の教材ビルドでは再分類しないため、原稿の順番を変更してもレベルは変わりません。初期分類用の `scripts/create-levels.cjs` は、分類を作り直す意思がある場合だけ実行してください。将来レベルを組み替える場合は保存済みの習得状況の移行も検討します。
